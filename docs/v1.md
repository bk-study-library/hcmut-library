# Dữ liệu công khai v1

Thư viện xuất dữ liệu ở `<site>/v1/` để web và app BK Study Desk cùng đọc. File trong thư mục `v1/` của repo do `npm run build` sinh ra, không sửa tay.

- `<site>` hiện là `https://bk-study-library.github.io/hcmut-library/`. Khi gắn tên miền riêng, `site` trong `index.json` đổi theo; bên đọc nên lấy địa chỉ gốc từ cấu hình, không ghi cứng.
- Code dựng: `scripts/lib/v1.mjs`. Test hợp đồng: `test/v1.test.mjs`.

## Cam kết

1. Đổi tên, xóa hay đổi nghĩa một trường thì ra `/v2/`, và `/v1/` còn ít nhất 6 tháng sau đó.
2. Thêm trường mới, thêm loại tài liệu mới không tính là thay đổi phá vỡ. Bên đọc bỏ qua trường lạ; gặp loại tài liệu lạ thì xếp vào nhóm "Khác".
3. Trường tùy chọn vắng mặt khi không có giá trị. Không dùng `null`.
4. Ngày dạng `YYYY-MM-DD`.
5. Dữ liệu không đổi thì file không đổi (cùng nội dung từng byte), nên ETag của GitHub Pages giữ nguyên và bên đọc dùng được `If-None-Match`.

## `v1/index.json`

Danh sách môn, đủ nhẹ để tải một lần rồi tìm và ghép môn.

| Trường | Kiểu | Ghi chú |
|---|---|---|
| `schemaVersion` | số | luôn là `1` |
| `generated` | ngày | ngày dữ liệu đổi gần nhất |
| `site` | chuỗi | địa chỉ gốc của web, kết thúc bằng `/` |
| `counts` | `{ courses, items }` | `items` chỉ đếm mục chưa gỡ |
| `faculties` | `[{ key, name: { vi, en } }]` | |
| `courses` | mảng | xem bảng dưới |

Mỗi môn:

| Trường | Kiểu | Ghi chú |
|---|---|---|
| `id` | chuỗi | ID cố định, khớp `^[A-Z0-9_]{3,12}(-[0-9]{4})?$`. Trường dùng lại mã cho môn khác thì môn sau có hậu tố năm khóa, ví dụ `GE4169-2024` |
| `code` | chuỗi | mã môn hiện tại. Hai môn có thể cùng `code` khi mã bị dùng lại |
| `name` | chuỗi | tên tiếng Việt hiện tại |
| `nameEn` | chuỗi, tùy chọn | |
| `credits` | số, tùy chọn | |
| `faculty` | chuỗi | khóa trong `faculties` |
| `levels` | mảng chuỗi, tùy chọn | bậc có môn này trong CTĐT: `dai-hoc`, `thac-si`, `tien-si` (thêm từ 04/10/2026). Chỉ có khi môn có ở sau đại học; vắng nghĩa là môn đại học. Môn chỉ có ở sau đại học thì không có `dai-hoc`. Gặp giá trị lạ thì coi như bậc khác |
| `aliases` | mảng chuỗi | mã cũ |
| `oldNames` | mảng chuỗi | tên cũ |
| `status` | `active` hoặc `retired` | |
| `replacedBy` | chuỗi, tùy chọn | ID môn thay thế khi môn đã ngừng |
| `items` | số | số mục chưa gỡ |
| `teachers` | mảng chuỗi, tùy chọn | tên giảng viên ghi trong các mục chưa gỡ, xếp theo chữ cái. Vắng khi chưa mục nào ghi |
| `url` | chuỗi | trang môn trên web |
| `detail` | chuỗi | đường dẫn file chi tiết, tính từ thư mục `v1/` |

## `v1/courses/<id>.json`

`{ schemaVersion, id, code, name, items }`. Mỗi môn đều có file này, kể cả môn chưa có tài liệu.

Mục còn hiệu lực:

| Trường | Kiểu | Ghi chú |
|---|---|---|
| `id` | chuỗi | `a-z0-9-`, cố định |
| `type` | chuỗi | xem danh sách loại |
| `title`, `lang`, `license`, `origin`, `added`, `updated` | chuỗi | `license` theo SPDX; `origin` là `self-made`, `link` hoặc `partner:<tên>`; `updated` là ngày file đổi gần nhất |
| `description`, `term`, `teacher`, `examKind`, `chapter`, `lab`, `source` | chuỗi, tùy chọn | `term` dạng `HK251`; `examKind` là `gk`, `ck`, `quiz` hoặc `kt` |
| `authors` | mảng chuỗi, tùy chọn | vắng khi tác giả ẩn danh |
| `example` | `true`, tùy chọn | mục mẫu |
| `url` | chuỗi | chỉ có ở loại `link` |
| `files` | mảng | không có ở loại `link` và `book-ref`. Mỗi file: `{ name, mime, size, sha256, urls }`; `mime` luôn có (loại nội dung, ví dụ `application/pdf`); `urls` có ít nhất một link, thử lần lượt, kiểm `sha256` sau khi tải |
| `book` | đối tượng | chỉ có ở loại `book-ref`: `{ title, authors, year?, publisher?, isbn? }`. Mục này chỉ ghi tên sách, không có `files` và `url` |

Mục có file mà chưa có link tải nào thì chưa xuất ra `v1/`.

Mục đã gỡ chỉ còn `{ id, type, removed: true, removedReason, added }`. Bên đọc ẩn mục này và xóa bản đã lưu của nó.

## `v1/majors.json`

Danh sách ngành (thêm từ 04/10/2026). Chương trình theo khóa chưa thuộc v1.

| Trường | Kiểu | Ghi chú |
|---|---|---|
| `schemaVersion` | số | luôn là `1` |
| `generated` | ngày | ngày danh sách ngành đổi gần nhất (`updated` của `catalog/majors.json`) |
| `site` | chuỗi | như trong `index.json` |
| `majors` | mảng | xem bảng dưới |

Mỗi ngành:

| Trường | Kiểu | Ghi chú |
|---|---|---|
| `code` | chuỗi | mã ngành Bộ, 7 chữ số. Nguồn dùng mã biến thể thì giữ nguyên, ví dụ `75202TT`, hay `7520201+7520207` cho song ngành |
| `name` | chuỗi | tên tiếng Việt |
| `nameEn` | chuỗi, tùy chọn | |
| `faculty` | chuỗi | khóa trong `faculties` của `index.json` |
| `level` | chuỗi | bậc đào tạo: `dai-hoc`, `thac-si` (mã ngành 8xxxxxx), `tien-si` (mã 9xxxxxx); ngành thạc sĩ, tiến sĩ có từ 04/10/2026. Gặp giá trị lạ thì coi như bậc khác. App chỉ cần ngành đại học thì lọc `level` là `dai-hoc` |
| `programTypes` | mảng chuỗi | loại chương trình: `CQ` chính quy, `CTTA` dạy bằng tiếng Anh, `CNTN` tài năng, `PFIEV`, `SN` song ngành, `CTTT` tiên tiến, `DHNB` định hướng Nhật Bản, `VLVH` vừa làm vừa học, `CTQT` chuyển tiếp quốc tế. Sau đại học: `UD` thạc sĩ ứng dụng, `NC` thạc sĩ nghiên cứu, `CSAU` thạc sĩ nghiên cứu chuyên sâu, `TAUD` thạc sĩ ứng dụng dạy bằng tiếng Anh, `STEM` thạc sĩ tài năng STEM, `PT1`, `PT2` tiến sĩ phương thức 1, 2, `TAPT1` tiến sĩ phương thức 1 dạy bằng tiếng Anh; `CQ` ở sau đại học là CTĐT trước khóa 2025 chưa chia hướng. Gặp mã lạ thì hiện mã |
| `aliases` | mảng chuỗi, tùy chọn | mã ngành khác mà nguồn dùng cho cùng ngành (thêm từ 04/10/2026), ví dụ `85202a1` của `8520202`. Mã chính chờ trường xác nhận |
| `handbookUrl` | chuỗi, tùy chọn | trang ngành trên Sổ tay HCMUT |
| `url` | chuỗi | trang ngành trên web (`major/<mã>/`, dấu `+` đổi thành `-`) |

## Loại tài liệu

| `type` | Nhãn |
|---|---|
| `lecture-slides` | Slide bài giảng |
| `summary` | Tóm tắt |
| `notes` | Ghi chú |
| `cheatsheet` | Bảng công thức |
| `quiz-pack` | Gói quiz (Study Pack v1) |
| `tips` | Mẹo học |
| `exercise-solution` | Lời giải bài tập |
| `exam-past` | Đề cũ |
| `exam-solution` | Lời giải đề |
| `prelab-template` | Mẫu prelab |
| `prelab-reference` | Prelab tham khảo |
| `lab-report-reference` | Báo cáo thí nghiệm tham khảo |
| `project-reference` | Bài tập lớn tham khảo |
| `book-ref` | Sách tham khảo (chỉ ghi tên) |
| `link` | Link tới tài liệu công khai |

Mọi loại ở trên đều được nhận; danh sách nằm ở `openTypes` trong `catalog/policy.json`. Điều duy nhất bị cấm là file sách có bản quyền, nên sách chỉ vào thư viện dưới loại `book-ref`. Bên đọc vẫn nên xếp loại lạ vào nhóm "Khác".

## Tìm kiếm

Logic tìm nằm ở `site-src/assets/search-core.js`: JS thuần, không DOM, nạp như script thường và gắn `BkSearch` vào `globalThis`. Bộ câu tìm mẫu ở `test/search-cases.json`; web và app phải qua hết bộ này.

`score` nhỏ là khớp hơn và có thể là số lẻ: mã hiện tại 0, mã cũ 0.25, đầu mã 1, viết tắt 1.5, khớp theo từ từ 2 đến 4. Môn đã ngừng cộng 0.5; môn chỉ có ở sau đại học (`levels` không có `dai-hoc`) cộng 0.5 khi không khớp đúng mã, để môn đại học đứng trước. Khi khớp theo từ, tên bắt đầu bằng cả cụm câu tìm (hoặc bằng đúng câu tìm) được trừ điểm, và câu tìm gõ có dấu được trừ thêm khi mọi từ khớp nguyên dấu (nên "vẽ kỹ thuật" xếp "Vẽ kỹ thuật" trên "Nhập môn về kỹ thuật"). Bên đọc chỉ nên so sánh thứ tự, không dựa vào giá trị cụ thể.
