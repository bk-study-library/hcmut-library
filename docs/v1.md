# Dữ liệu công khai v1

Thư viện xuất dữ liệu ở `<site>/v1/` để web và app BK Study Desk cùng đọc. File trong thư mục `v1/` của repo do `npm run build` sinh ra, không sửa tay.

- `<site>` hiện là `https://bk-study-library.github.io/bk-study-library/`. Khi gắn tên miền riêng, `site` trong `index.json` đổi theo; bên đọc nên lấy địa chỉ gốc từ cấu hình, không ghi cứng.
- Code dựng: `scripts/lib/v1.mjs`. Test hợp đồng: `test/v1.test.mjs`.

## Cam kết

1. Đổi tên, xóa hay đổi nghĩa một trường thì ra `/v2/`, và `/v1/` còn ít nhất 6 tháng sau đó.
2. Thêm trường mới, thêm loại tài liệu mới không tính là thay đổi phá vỡ. Bên đọc bỏ qua trường lạ; gặp loại tài liệu lạ thì xếp vào nhóm "Khác".
3. Trường tùy chọn vắng mặt khi không có giá trị. Không dùng `null`.
4. Ngày dạng `YYYY-MM-DD`.
5. Dữ liệu không đổi thì file không đổi (cùng nội dung từng byte), nên ETag của GitHub Pages giữ nguyên và bên đọc dùng được `If-None-Match`.

## `v1/index.json`

Danh sách môn, đủ nhẹ để tải một lần rồi tìm và ghép môn.

| Trường | Kiểu | Ghi chú |
|---|---|---|
| `schemaVersion` | số | luôn là `1` |
| `generated` | ngày | ngày dữ liệu đổi gần nhất |
| `site` | chuỗi | địa chỉ gốc của web, kết thúc bằng `/` |
| `counts` | `{ courses, items }` | `items` chỉ đếm mục chưa gỡ |
| `faculties` | `[{ key, name: { vi, en } }]` | |
| `courses` | mảng | xem bảng dưới |

Mỗi môn:

| Trường | Kiểu | Ghi chú |
|---|---|---|
| `id` | chuỗi | ID cố định, khớp `^[A-Z0-9_]{3,12}(-[0-9]{4})?$`. Trường dùng lại mã cho môn khác thì môn sau có hậu tố năm khóa, ví dụ `GE4169-2024` |
| `code` | chuỗi | mã môn hiện tại. Hai môn có thể cùng `code` khi mã bị dùng lại |
| `name` | chuỗi | tên tiếng Việt hiện tại |
| `nameEn` | chuỗi, tùy chọn | |
| `credits` | số, tùy chọn | |
| `faculty` | chuỗi | khóa trong `faculties` |
| `aliases` | mảng chuỗi | mã cũ |
| `oldNames` | mảng chuỗi | tên cũ |
| `status` | `active` hoặc `retired` | |
| `replacedBy` | chuỗi, tùy chọn | ID môn thay thế khi môn đã ngừng |
| `items` | số | số mục chưa gỡ |
| `url` | chuỗi | trang môn trên web |
| `detail` | chuỗi | đường dẫn file chi tiết, tính từ thư mục `v1/` |

## `v1/courses/<id>.json`

`{ schemaVersion, id, code, name, items }`. Mỗi môn đều có file này, kể cả môn chưa có tài liệu.

Mục còn hiệu lực:

| Trường | Kiểu | Ghi chú |
|---|---|---|
| `id` | chuỗi | `a-z0-9-`, cố định |
| `type` | chuỗi | xem danh sách loại |
| `title`, `lang`, `license`, `origin`, `added`, `updated` | chuỗi | `license` theo SPDX; `origin` là `self-made`, `link` hoặc `partner:<tên>`; `updated` là ngày file đổi gần nhất |
| `description`, `term`, `teacher`, `examKind`, `chapter`, `lab`, `source` | chuỗi, tùy chọn | `term` dạng `HK251`; `examKind` là `gk`, `ck`, `quiz` hoặc `kt` |
| `authors` | mảng chuỗi, tùy chọn | vắng khi tác giả ẩn danh |
| `example` | `true`, tùy chọn | mục mẫu |
| `url` | chuỗi | chỉ có ở loại `link` |
| `files` | mảng | không có ở loại `link` và `book-ref`. Mỗi file: `{ name, mime, size, sha256, urls }`; `mime` luôn có (loại nội dung, ví dụ `application/pdf`); `urls` có ít nhất một link, thử lần lượt, kiểm `sha256` sau khi tải |
| `book` | đối tượng | chỉ có ở loại `book-ref`: `{ title, authors, year?, publisher?, isbn? }`. Mục này chỉ ghi tên sách, không có `files` và `url` |

Mục đã gỡ chỉ còn `{ id, type, removed: true, removedReason, added }`. Bên đọc ẩn mục này và xóa bản đã lưu của nó.

## Loại tài liệu

| `type` | Nhãn | Đang nhận |
|---|---|---|
| `summary` | Tóm tắt | có |
| `notes` | Ghi chú | có |
| `cheatsheet` | Bảng công thức | có |
| `quiz-pack` | Gói quiz (Study Pack v1) | có |
| `tips` | Mẹo học | có |
| `link` | Link tới tài liệu công khai | có |
| `book-ref` | Sách tham khảo (chỉ ghi tên) | có |
| `exercise-solution` | Lời giải bài tập tự làm | chưa |
| `exam-past` | Đề cũ đã công khai | chưa |
| `exam-solution` | Lời giải đề tự làm | chưa |
| `prelab-template` | Mẫu prelab | chưa |
| `prelab-reference` | Prelab tham khảo | chưa |
| `lab-report-reference` | Báo cáo thí nghiệm tham khảo | chưa |
| `project-reference` | Bài tập lớn tham khảo | chưa |

Loại đang nhận nằm ở `catalog/policy.json`. Các loại "chưa" chỉ mở khi có người duyệt thứ hai và quy định riêng về liêm chính học thuật.

## Tìm kiếm

Logic tìm nằm ở `site-src/assets/search-core.js`: JS thuần, không DOM, nạp như script thường và gắn `BkSearch` vào `globalThis`. Bộ câu tìm mẫu ở `test/search-cases.json`; web và app phải qua hết bộ này.
