Takedown

If an item infringes your copyright, exposes your personal information or breaks the rules, report it and it comes down. Target: handled within one business day.

Who can ask

  • The author or copyright holder (a lecturer, a faculty, a publisher).
  • Anyone whose personal information appears in an item.
  • The person who sent the item and wants to withdraw it.
  • Anyone who finds a copyrighted book file in the library.

How to ask

  1. Open the Takedown request form.
  2. Paste the course page link or the item title and choose a reason.
  3. Don't copy the personal information into the issue: issues are public. A link to the item is enough.
  4. If you need to talk privately, write "need private contact" and the maintainer replies with a way to reach them.

What the library does

  1. Hides the item as soon as a well-founded request arrives: deletes the file from the GitHub release (a deleted asset is gone for good) and sets removed: true with a short reason in the item.
  2. Keeps the item title on the course page with a "Removed" label, so old links still work.
  3. If personal information is in the Git history, the maintainer rewrites the history and asks GitHub to clear cached views.
  4. Replies in the issue and closes it.
