Đóng góp tài liệu

Thư viện có bài là nhờ sinh viên gửi và duyệt cho nhau. Gửi bài không cần tài khoản GitHub.

Tài liệu nào được đăng

Mọi tài liệu học tập bạn tự làm hoặc có quyền chia sẻ, kể cả đề cũ, báo cáo, bài tập lớn và gói quiz của BK Study Desk.

Chỉ không nhận file sách có bản quyền. Muốn giới thiệu một cuốn sách, chọn loại Sách tham khảo và ghi tên sách, tác giả, ISBN, không kèm file.

Form chỉ nhận các đuôi file ghi trên form. File có virus bị chặn.

Cách 1: gửi qua form

  1. Mở Gửi tài liệu, hoặc bấm Gửi tài liệu trên trang môn để form chọn sẵn môn.
  2. Chọn môn, loại tài liệu, nhập tiêu đề, chọn file. File .zip chỉ dùng cho loại Gói quiz; loại khác thì gửi từng file hoặc gộp thành một file PDF.
  3. Chọn giấy phép và đánh dấu ba ô xác nhận.
  4. Bấm Gửi tài liệu. Trang hiện mã bài, bạn lưu lại mã này.

Chỉ có link, không có file? Dùng form Thêm link (cần tài khoản GitHub).

Thiếu chương trình đào tạo của khóa bạn? Gửi link hoặc file qua form Thêm chương trình đào tạo (cần tài khoản GitHub).

Cách 2: Pull Request (nếu bạn dùng Git)

  1. Fork repo, thêm courses/<ID>/items/<id>.json. Cách này chỉ nhận thông tin tài liệu (JSON) và file .md dưới 1 MB, đặt ở courses/<ID>/files/. File khác thì gửi qua form.
  2. Chạy npm test và npm run build, rồi commit cả generated file.
  3. Mở Pull Request và đánh dấu checklist.

Chi tiết các trường: CONTRIBUTING.md.

Thông tin cá nhân

Thư viện không cấm thông tin cá nhân, nhưng sẽ cảnh báo khi thấy MSSV, email hay số điện thoại trong bài. Tốt nhất bạn tự xóa trước khi gửi. Form không hỏi email; bỏ trống tên hiển thị thì bài ghi Ẩn danh. Cách thư viện xử lý dữ liệu: PRIVACY.md.

Sau khi gửi

  • Mã bài: dùng mã này khi hỏi về bài của bạn.
  • Thời gian duyệt: người duyệt cố trả lời trong 7 ngày. Bài được duyệt sẽ hiện trên trang môn. Xem cách duyệt bài.
  • Muốn gỡ bài: xem Gỡ tài liệu.
