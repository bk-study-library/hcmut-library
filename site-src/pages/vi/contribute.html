Đóng góp tài liệu

Thư viện sống nhờ sinh viên gửi bài và duyệt bài cho nhau. Bạn không cần biết Git: điền form trên GitHub, đính kèm file là xong.

Được đăng

  • Tài liệu bạn tự soạn: tóm tắt, ghi chú, bảng công thức, lời giải bạn tự làm, mẫu prelab (khung báo cáo, câu hỏi chuẩn bị, không có số liệu đã chấm).
  • Gói quiz theo định dạng Study Pack v1 của BK Study Desk.
  • Link tới tài liệu công khai, hợp pháp: giáo trình mở (OpenStax, MIT OpenCourseWare...), video công khai, trang của khoa.
  • Prelab hoặc báo cáo tham khảo, chỉ sau khi đã hết hạn nộp và hết hạn chấm, ghi rõ là bản tham khảo.

Không đăng

  • Slide, giáo trình, đề thi, đáp án của giảng viên hoặc của trường khi chưa có phép bằng văn bản.
  • File chép từ Scribd, Studocu, Course Hero hay trang tương tự.
  • Bài có MSSV, họ tên, chữ ký, email, số điện thoại, ảnh mặt người (của bạn hay của người khác).
  • Bài đang trong hạn nộp hoặc hạn chấm.
  • File chạy được (.exe, .bat...), file trên 20 MB.

Cách 1: gửi qua form, không cần Git

  1. Đăng nhập GitHub (tạo tài khoản miễn phí nếu chưa có).
  2. Mở form Đóng góp tài liệu, hoặc chọn Gửi tài liệu trên trang môn để form điền sẵn mã môn.
  3. Điền mã môn, loại, tiêu đề, học kỳ; đánh dấu ba ô cam kết (tự soạn, đồng ý giấy phép CC BY-SA 4.0, đã xóa thông tin cá nhân).
  4. Kéo file vào ô File đính kèm. GitHub nhận file đính kèm tới 25 MB cho tài liệu và .zip, 10 MB cho ảnh; thư viện chỉ nhận tới 20 MB. File KiCad và nhiều file một lúc thì nén thành .zip.
  5. Gửi. Người duyệt sẽ trả lời ngay trong issue.

Chỉ có link? Dùng form Thêm link.

Cách 2: Pull Request (nếu bạn dùng Git)

  1. Fork repo, thêm courses/<ID>/items/<id>.json. File .md nhỏ (dưới 1 MB) đặt ở courses/<ID>/files/; PDF, .docx, ảnh, .zip không đưa vào git, người duyệt sẽ tải lên GitHub Release.
  2. Chạy npm test và npm run build, rồi commit cả file sinh ra.
  3. Mở Pull Request và đánh dấu checklist.

Chi tiết các trường: CONTRIBUTING.md.

Sau khi gửi
