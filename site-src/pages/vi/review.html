Duyệt bài

Mọi tài liệu đều được kiểm trước khi lên thư viện. Người duyệt là sinh viên tình nguyện.

Ai duyệt

  • Hiện tại: người duy trì repo (@xeroz369), ghi trong file .github/CODEOWNERS.
  • Khi có thêm người, mỗi khoa hoặc nhóm môn có người duyệt riêng, cũng ghi trong CODEOWNERS theo thư mục môn. GitHub tự mời đúng người duyệt khi có Pull Request.
  • Muốn duyệt cho môn bạn giỏi: mở form Đăng ký duyệt bài.

Bài đi qua những bước nào

  1. Gửi: qua trang Gửi tài liệu (bot mở một Pull Request cho bài), qua form Thêm link (issue có nhãn cần duyệt, người duyệt tự tạo Pull Request từ issue), hoặc bạn tự mở Pull Request.
  2. Kiểm tự động: với file gửi qua trang web, workflow kiem-file quét virus, xóa siêu dữ liệu (PDF, ảnh, file Office), cảnh báo MSSV, email, số điện thoại, JavaScript trong PDF, macro trong Office, rồi ghi link Release vào Pull Request. CI validate kiểm định dạng, loại file, dung lượng và file trùng.
  3. Người duyệt đọc: theo danh sách bên dưới, hỏi lại người gửi trong Pull Request hoặc issue nếu cần.
  4. Merge: người duyệt merge Pull Request. Workflow phat-hanh-file đưa file lên GitHub Release files-HKxxx (pre-release). Pull Request bị đóng thì don-kho dọn file chờ duyệt.
  5. Đóng issue (với link) kèm link tới trang môn.

Mục tiêu: trả lời mọi bài gửi trong 7 ngày. Yêu cầu gỡ được xử lý trước, xem Gỡ tài liệu.

Danh sách kiểm của người duyệt

  • PR có dòng Môn mới: kiểm mã, tên và khoa của môn với Sổ tay HCMUT (link trong PR). Trùng môn đã có thì đóng PR và nhờ người gửi chọn môn đó.
  • Không phải file sách có bản quyền. Sách thì chuyển thành loại Sách tham khảo, chỉ ghi tên.
  • Thông tin cá nhân: xem cảnh báo của máy trong PR rồi quyết. Máy chỉ cảnh báo, không chặn.
  • Giấy phép: tự soạn thì CC BY-SA 4.0 (hoặc CC BY 4.0, CC0); link thì ghi đúng giấy phép của nguồn.
  • Nội dung đúng môn, đúng loại, tiêu đề rõ, không quảng cáo.
  • File .zip (chỉ có ở gói quiz): mở ra xem, không có file chạy được.
  • PR có nhãn can-xem-tay: máy không kết luận được, đọc lý do trong comment rồi mở file trên máy có phần mềm diệt virus.
  • Chữ người gửi đã công khai trong file mục của PR ngay khi gửi: có chữ xúc phạm, quảng cáo hay link lạ thì đóng PR ngay.
